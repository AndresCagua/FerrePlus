# YouTube publication package — Chapter 7

## Title

**Chat IA de FerrePlus: embeddings, pgvector y RAG | Capítulo 7**

## Description

En este capítulo seguimos el flujo del asistente IA de FerrePlus dentro del panel administrativo.

Veremos:

- Widget de chat autenticado.
- POST `/api/chat`.
- Clasificación de intención con TypeSafe Jev.
- Diferencia entre consultas analíticas y RAG.
- Embeddings de Gemini.
- Búsqueda semántica con pgvector.
- Construcción del contexto.
- Fuentes devueltas junto con la respuesta.
- Whitelist, consultas de solo lectura y fallback seguro.

La demostración usa el entorno local y no muestra tokens, API keys, prompts privados, datos personales ni respuestas sensibles.

Repositorio del proyecto:

https://github.com/AndresCagua/FerrePlus
