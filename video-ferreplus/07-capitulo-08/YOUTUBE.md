# YouTube publication package — Chapter 8

## Title

**Seguridad en FerrePlus: JWT, CORS, rate limiting y Turnstile | Capítulo 8**

## Description

En este capítulo revisamos cómo FerrePlus protege sus APIs y formularios públicos.

Veremos:

- JWT y autorización backend.
- Tokens S2S entre servicios.
- Secretos fuera de Git.
- CORS, headers defensivos y validación.
- Rate limiting con Redis y fallback conservador.
- Cloudflare Turnstile.
- Logging seguro y límites de una demostración técnica.

Las capturas se realizan en el entorno local y no muestran credenciales, JWTs, claves privadas, tokens Turnstile, CVs, datos personales ni logs sensibles.

Repositorio del proyecto:

https://github.com/AndresCagua/FerrePlus
