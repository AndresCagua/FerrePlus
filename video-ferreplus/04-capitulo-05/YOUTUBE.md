# YouTube publication package — Chapter 5

## Title

**APIs de FerrePlus: DTOs, validación y límites de responsabilidad | Capítulo 5**

## Description

En este capítulo seguimos el recorrido de las peticiones HTTP de FerrePlus y observamos cómo se separan las responsabilidades entre sus APIs.

Veremos:

- Diferencia entre `admin-api` y `public-api`.
- Contratos HTTP y rutas públicas.
- Autenticación y permisos en la API administrativa.
- DTOs y validación de entradas.
- Respuestas de error controladas.
- Flujo completo de una petición.
- Separación entre cliente, API, servicios y almacenamiento.

Las demostraciones se ejecutan en el entorno local con datos ficticios. No se incluyen credenciales, tokens, API keys, secretos ni información personal.

Repositorio del proyecto:

https://github.com/AndresCagua/FerrePlus
