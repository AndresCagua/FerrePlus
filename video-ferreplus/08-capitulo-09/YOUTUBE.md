# YouTube publication package — Chapter 9

## Title

**Cloudflare Tunnel en FerrePlus: Quick Tunnel, named tunnel y Traefik | Capítulo 9**

## Description

En este capítulo explicamos cómo FerrePlus puede conectar Cloudflare con su entorno local mediante `cloudflared` y Traefik.

Veremos:

- Diferencia entre Quick Tunnel y named tunnel.
- Perfil opcional `tunnel` de Docker Compose.
- Token montado como Docker secret.
- Flujo Cloudflare Edge → cloudflared → Traefik → aplicación.
- Imagen fijada y actualización controlada con `--no-autoupdate`.

La demostración muestra configuración segura y no expone tokens, URLs públicas activas, credenciales ni logs sensibles.

Repositorio del proyecto:

https://github.com/AndresCagua/FerrePlus
