# YouTube publication package — Chapter 4

## Title

**Interfaces web de FerrePlus: portal público, panel Angular y APIs | Capítulo 4**

## Description

En este capítulo recorremos las interfaces web de FerrePlus desde la perspectiva del usuario.

Veremos:

- El portal público construido con Astro.
- Navegación por publicaciones y convocatorias.
- Inicio de sesión en el panel administrativo.
- Navegación del panel Angular.
- Módulos administrativos y consumo de APIs.
- Estados de carga, estados vacíos y errores.
- Autenticación y permisos.
- Integración visible del chat IA.

Las demostraciones se realizan con el entorno local y datos ficticios. No se incluyen credenciales, tokens, API keys, secretos ni información personal.

Repositorio del proyecto:

https://github.com/AndresCagua/FerrePlus
