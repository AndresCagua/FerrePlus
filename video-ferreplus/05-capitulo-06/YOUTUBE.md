# YouTube publication package — Chapter 6

## Title

**Persistencia en FerrePlus: PostgreSQL, MongoDB, Redis y MinIO | Capítulo 6**

## Description

En este capítulo revisamos cómo FerrePlus distribuye la información entre sus sistemas de persistencia y almacenamiento.

Veremos:

- PostgreSQL para la operación administrativa.
- MongoDB para el contenido público.
- Redis para rate limiting y estado auxiliar.
- MinIO para medios y archivos.
- Ownership de datos y redes internas.
- Volúmenes, healthchecks y límites de comunicación.

Las demostraciones se ejecutan en el entorno local con comandos seguros. No se incluyen contraseñas, tokens, archivos privados ni información personal.

Repositorio del proyecto:

https://github.com/AndresCagua/FerrePlus
