# YouTube publication package — Chapter 3

## Title

**Cómo levantar FerrePlus localmente: Docker Compose, healthchecks y diagnóstico | Capítulo 3**

## Description

En este capítulo levantamos FerrePlus en el entorno local y comprobamos que sus servicios estén listos para trabajar.

Veremos:

- Requisitos básicos para iniciar el proyecto.
- Configuración local y manejo seguro de variables.
- Construcción y arranque mediante Docker Compose.
- Dependencias entre servicios.
- Diferencia entre un contenedor iniciado y uno saludable.
- Healthchecks con `docker compose ps`.
- Diagnóstico mediante logs recientes.
- Comprobación del dashboard y del portal público.
- Detención segura sin eliminar los volúmenes locales.

Todo el material visual corresponde al entorno local de FerrePlus. No se incluyen credenciales, tokens, API keys, secretos ni datos personales.

Repositorio del proyecto:

https://github.com/AndresCagua/FerrePlus
